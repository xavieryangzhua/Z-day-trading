# Z-day-trading

简洁的本地 SPY 分钟级交易研究工具。只模拟买 Call，不下单，不接 LLM API。

## 启动

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

打开 http://127.0.0.1:8510，或安装后双击 `Start.command`。

## 四个页面

- **想法**：买入想法和公共卖出方法分别新增、保存、编辑名称与 description。修改描述后自动设 `realize=false`；也可手动勾选重新实现。只改名称不使结果失效。
- **想法库**：一张表列出所有已实现和待实现的买入想法、卖出方法，只显示名称、类型和状态。直接让 Codex “实现并回测待处理想法”；不调用 API。
- **结果**：一次显示一个买入想法，对比公共卖出方法的平均单笔净收益率、胜率、交易次数。规则改动后不把旧结果当新结果展示。

- **排名**：按最新有效回测的平均单笔净收益率降序，展示全部买入＋卖出组合、胜率、盈利笔数及交易笔数。未回测和失效结果不参与排名；无交易组合收益留空并排在最后。

## 文件与版本

`seed_ideas.json` 提供三个初始买入想法和五个公共卖出方法。首次运行生成 `storage/ideas.json`，这是你编辑的工作文件。`storage/research.sqlite3` 保存每次回测的想法版本、卖出规则版本、行情来源、SHA256、计算参数、代码快照、汇总和逐笔交易。旧记录不覆盖。备份整个 storage 目录即可保存想法和历史结果。

```sh
.venv/bin/python manage.py pending
.venv/bin/python manage.py run
.venv/bin/python -m pytest -q
```

Codex 阅读 description 后，通过 `manage.py implement ID '{"type":"breakout","indicator":"vwap","confirmation":"close"}'` 等命令登记相符的实现。超出现有规则的想法需扩展引擎；不会把未知描述自动套成既有模板。没有已实现的公共卖出规则时不提交部分比较。

## 入场与退出

突破条件：A（本根 open < 本根指标，close > 本根指标）或 B（前一根 close < 前一根指标，本根 close > 本根指标），任一成立。等于指标不算突破或站上。第二根收盘确认，第三根开盘买入。

三个买入想法：VWAP 收盘确认、EMA20 收盘确认、VWAP 开盘和收盘均在第二根 VWAP 上方。条件均在第二根收盘后确认，所以对开盘的比较也使用该根已完成指标。VWAP 按 HLC3×成交量计算，每天重置；EMA20 使用常规时段连续 K 线，跨日保留、最少预热20根；信号组合不跨日。

固定卖出为持有1/5/10/30分钟，对应分钟结束时用收盘价卖出；剩余交易时间不足则在当日收盘退出。连续两根阳线从入场所在 K 线开始计数，阳线要求 close > open，阴线或十字星清零；第二根阳线结束时按本根收盘价卖出。未触发时当日最后一根收盘退出。

每个“买入想法＋卖出方法”独立模拟，不重叠持仓。统一按分钟开盘买入、分钟收盘卖出；退出后可在下一根开盘入场。不同卖出方法的持仓长度不同，所以有效入场样本可能不同。不隔夜。

## 收益

每笔买1张 Call：初始报价 $2/股，即 $200/张；Delta 0.5；报价每分钟减 $0.01，即每张减 $1；往返手续费 $2。

```
卖出报价 = max(0, 2 + 0.5 × (标的卖价 - 标的买价) - 0.01 × 实际持有分钟)
净损益 = (卖出报价 - 2) × 100 - 2
净收益率 = 净损益 / 200
```

显示平均单笔净收益率，不是累计账户收益率。无交易显示空值，不伪造零收益。固定 Delta 和时间损耗属于情景模拟，未使用真实期权报价、IV、Gamma、点差或滑点。归零后含手续费最多损失 $202。

## 行情来源

复用旧项目的 `SPY_1min_2025-01-02_2025-04-28.csv`，常规交易时段 79 天、30,810 根1分钟K线。来源和原始下载地址、固定源提交及SHA256见 `data/source.json`：第三方 SPY-Analysis 仓库中的 Databento XNAS.ITCH（Nasdaq 单一场所），不是全市场合并成交量。新项目使用独立 SQLite，不混入旧策略结果。

行情不提交 Git；在其他机器使用时需自行将同一 CSV 放入 data/。引擎核验文件哈希、OHLC、时间顺序和完整分钟；不补值，不把残缺交易日的最后一根冒充收盘。当前校验针对这份完整的正常长度交易日数据；未来加入半日市数据需同步扩展交易日历支持。

## 2026-10-23 新想法

新增9个买入想法、4个卖出方法。`updates/apply_20261023.py` 导入原始想法，`updates/confirm_20261023.py` 登记用户确认后的6条精确定义；两个脚本均支持重复执行而不重复新增条目。

- 连续8/9根阴线与20根中至少17根阴线，均只检查当日已结束K线；下一根开盘入场。
- 阴线实体下跌严格超过1/2/3美元；三分钟累计下跌严格超过3美元，累计跌幅按第一根开盘减第三根收盘计算。
- EMA5/20回调：回调之前5根收盘均高于各自EMA，回调根为阴线，收盘距离本根EMA不超过0.10美元，下一根开盘入场。EMA跨正常交易时段连续计算，信号窗口不跨日。
- 新增固定3分钟退出。
- 第一根或第三根收盘相比入场价上涨严格超过0.25美元才退出；仅在指定根检查，未触发则当天收盘退出。这两条并非移动止盈，也不是固定1/3分钟退出。
- 期权目标：最多10分钟，每根收盘按已含时间损耗的模拟期权报价检查，首次严格超过2.50美元即退出；未达标则第10分钟收盘退出。手续费在计算净收益时另扣。

所有成交统一分钟开盘买入、分钟收盘卖出。数据库 `ideas` 表同步全部想法（包括待实现条目），`runs` 保留每次回测版本快照。修改描述不会覆盖历史回测。

## 自主探索：急跌后确认

`updates/explore_call.py` 固定新增3个买入条件（阴线跌超1.5美元、3分钟跌超2美元、阴线跌超1美元后紧接一根阳线确认）和3个卖出方法（2分钟、15分钟、期权涨超25%止盈或跌15%止损并最多10分钟）。所有新增条目均标明规则，使用统一费用及成交口径，没有按结果循环搜索参数。

`updates/review_call.py` 从最新保存的逐笔交易输出全期、1—3月、4月的样本数、净收益和胜率，并检查去掉收益最高交易日后的总净损益。输出位于 `storage/call-exploration-summary.json`。这些时期已经用于前面的研究，分段检查不是独立样本外验证。当前排名显示所有180个有效组合，按平均净收益排序，表格可滚动查看。

## 顺势研究

`updates/trend_call.py` 新增3个有详细description的买入想法：上升EMA20回调确认、上升EMA20背景下EMA5回调确认、顺势突破前10根最高价。前两者需回调前5根收盘在线上、EMA20高于5根前、阴线低点距目标EMA不超过0.10且收盘守住均线，紧接的阳线收盘突破回调根最高价后下一根开盘入场；第三种在前10根收盘均在EMA20上方、EMA20抬升时，阳线收盘突破前10根最高价，下一根开盘入场。所有条件在当日已完成K线上计算。

每次信号只买1张Call，不叠加仓位；平仓后可以响应新的独立信号。这是独立交易研究，不是持续加仓或网格策略。新增36组均保留，无论收益正负；全部18×12=216组可在排名查看。当前固定Delta及费用口径下，新增36组全期平均净收益均为负，不能据此推断所有趋势策略都无效。

## 非EMA20趋势研究

`updates/alternative_trends.py` 新增VWAP上升回调确认、SMA50上升突破确认、纯价格高低点抬高三种假设。详细步骤由 `updates/detail_descriptions.py` 生成并存入每个想法的description。VWAP按日重置；SMA50是50根正常时段收盘的简单平均，连续跨日预热；价格结构使用已完成的三个不重叠5根区间比较高低点，不使用未来K线确认波峰波谷。

固定参数测试新增36个组合，结果全期平均净收益均为负，全部保留；排名现共21×12=252组。保持Call单笔开仓、不加仓和开盘买入/收盘卖出口径，不因为结果不好而循环优化参数。

## 上涨后首次整理突破

`updates/platform_breakout.py` 登记5根上涨、紧接3根整理、最多等待3根阳线收盘突破的平台形态。上涨段至少3根阳线、累计上涨且EMA20抬升；整理低点守住上涨段高低点中位值且收盘均高于EMA20。等待阶段收盘跌破整理下沿或EMA20即取消，突破后下一分钟开盘买入。每个滚动候选最多触发一次，详细边界和失败条件保存在description中。

2025-01-02至2025-04-28的SPY分钟数据上，与现有12种卖出方法组合的平均单笔净收益均为负。最佳为持有1分钟：807笔、平均净收益率−2.06%、胜率31.23%；持有2分钟：690笔、−2.17%、33.62%。使用固定Delta=0.5、每张每分钟损耗1美元和往返手续费2美元的模拟口径，不代表真实期权成交收益。排名现共22×12=264组。新增形态边界测试及完整测试共49项通过，并核对成交价、分钟时点、持仓互斥及网页结果。
